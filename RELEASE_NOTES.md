- Keychange offers to launch at login the first time it runs without being set to.
- The menu bar mark keeps showing the current input source while Keychange is paused or
  switched off, and carries a pause or stop symbol for why it stopped.
- Language codes longer than two letters now show two instead of one: Hawaiian reads HA,
  Sorani Kurdish CK. Simplified and Traditional Chinese read ZS and ZT so they can be told
  apart.
- Changing **Switch layout** or **On external layout change** now forgets which keyboard you
  were typing on, so your next key press re-applies that keyboard's layout under the new
  setting.
- Fixed: with **Before key press**, a key press held back for a switch could be delivered
  before the switch landed, so the character came out in the previous layout.
