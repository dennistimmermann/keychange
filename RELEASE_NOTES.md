Keychange now updates itself. When a new version is out it offers to install and relaunch — no
more downloading a zip and dragging it to Applications. Builds are signed and notarized, so they
open with a double-click.

**The settings moved behind the cog** next to the switch in the header. Clicking it reveals the
settings, any devices you have hidden, and each device's vendor and product ID — the same reveal
you used to get only by holding ⌥ while opening the panel. Holding ⌥ still works.

- **Check for Updates…** lives in the About panel, next to the version it acts on
- **Check for updates automatically** sits with the other settings, and turns the update check off
  entirely — it is the only network request Keychange makes
- The "*n* connected" count is gone; the keyboard list already says that

Updating from 0.1.2 or earlier has to be done by hand this once — those builds have no updater in
them. From 0.2.0 onwards Keychange takes care of it.
